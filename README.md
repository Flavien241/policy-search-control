# Direct Policy Search for Reinforcement Learning

A two-person course project investigating direct optimisation of parameterised policies on `CartPole-v1` and `LunarLander-v3`.

## Contents

[`TPDirectSearch.ipynb`](TPDirectSearch.ipynb) implements deterministic and stochastic policy-search experiments, including repeated evaluations. The best policies found during the runs are saved as NumPy arrays for CartPole and LunarLander.

## Run

Use the Gym/Jupyter environment described by the project notebook, then run:

```bash
jupyter notebook TPDirectSearch.ipynb
```

## Context

Coursework completed at Polytech Lyon with a teammate. Results are reported in the notebook and should be interpreted within its random-seed and evaluation protocol.
